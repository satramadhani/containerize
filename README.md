# Containerize

A personal, `docker compose`-inspired tool/wrapper for Apple's [`container`](https://github.com/apple/container).

Built mainly to learn Swift and the ecosystem, so expect a lot of bugs, missing features, or inconsistencies; will be immediately obsoleted when Apple releases the official tool.

For a better, well-maintained tool, use [mcrich23/container-compose](https://github.com/mcrich23/container-compose).
